# たかがAI、あがけ人類 — ローカルプロトタイプ

人間とAIが同じ大喜利のお題へ回答し、匿名投票と肉体チャレンジで勝敗を決めるスマートフォン向けゲームのローカルプロトタイプです。

この版は外部APIやサーバーを使用せず、1つのブラウザ内で4人分のゲーム進行を体験できます。

## 起動方法

必要な環境：Node.js 20.19以上または22.12以上、npm

```bash
npm install
npm run dev
```

ターミナルに表示されたURL（通常は `http://localhost:5173`）を開いてください。

### UIの比較

- 統合プロトタイプ：`http://localhost:5173/`
- 既存UIを変更しない表示：`http://localhost:5173/?ui=original#/`
- 既存UIの画面一覧：`http://localhost:5173/?ui=original#/screens`

`ui=original`では、統合プロトタイプを追加する前から存在したReact Routerの各画面をそのまま表示します。

## プロトタイプの遊び方

1. 「ルームを作る」または「ルームに参加」を選ぶ
2. プレイヤー名を入力し、ロビーへ進む
3. 自分を「準備OK」にしてゲームを開始する
4. 挑戦者として大喜利へ回答する
5. 挑戦者以外の3人を順番に操作して回答A・Bへ投票する
6. AIが投票で勝った場合は、連打またはスマホ振りチャレンジで挽回する
7. 先に3ポイント取った側がゲームに勝利する

## 実装済み

- ルーム作成・参加のローカルUI
- 4人の模擬プレイヤーと準備状態
- 36問のお題から重複なしで出題
- 挑戦者の順番切り替え
- 1行・60文字以内の回答検証
- ローカルの模擬AI回答
- 回答A・Bのランダム匿名化
- 3人分の順番投票と結果公開
- 同票時の人類勝利ルール
- `deadlineAt` を基準にした回答・投票・チャレンジ時間
- 5秒35回の超連打チャレンジ
- 対応端末でのスマホ振りチャレンジ
- 挽回結果に応じた得点更新
- 3ポイント先取、ラウンド履歴、最終結果、再戦
- 幅320px以上のスマートフォン向けレスポンシブUI

## プロトタイプで模擬しているもの

- ほかのプレイヤー：同じブラウザで順番に操作
- AI回答：リポジトリ内の固定回答をお題ごとに選択
- ルームとゲーム状態：Reactのメモリ上で管理
- ルームコード：ブラウザ内で生成

ページを再読み込みするとゲーム状態は初期化されます。

## 本番化に必要なもの

- Cloudflare Workers / Durable Objectsによるルーム状態管理
- 複数端末を同期するWebSocket通信と再接続処理
- ルーム作成・参加用HTTP API
- OpenAI Responses APIとAI Gateway
- APIキーなどのWorker Secrets
- プレイヤーID・トークンによる操作認証
- サーバー側での回答・WebSocketメッセージ検証
- Durable Object Storageへのゲーム状態保存と期限切れ処理
- 実機4～5台でのモーションしきい値・通信・画面検証
- デプロイ先とHTTPS環境
